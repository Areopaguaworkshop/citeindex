Code vs README

Four documented discrepancies

Where the README's description of the digital PDF flow differs from what the source tree does.

  1. README says "PDF metadata remains a last-resort, unverified identity hint" (README.md:279-280).

    codeThe code never reads embedded PDF metadata; the title is always os.path.basename(pdf_path). digital_pdf.py:467 The real last resort is the filename-derived base_csl. common.py:404, extraction_method="metadata-only"

  2. README's flow orders "DSPy citation extraction → PageIndex tree" (README.md:181-186).

    codeThe code runs PageIndex (Step 4, digital_pdf.py:576) before citation extraction (Step 5, digital_pdf.py:590).

  3. README implies digital image extraction is unconditional (README.md:188).

    codeThe code gates it on cfg.use_layout_analysis. digital_pdf.py:520

  4. README lists GROBID as a cascade tail (README.md:183).

    codeWhen selected it replaces DSPy entirely (digital_pdf.py:602-607) and its failure aborts ingestion rather than falling through.

All callouts, thresholds, function names, and file:line references on this page were traced from the CiteIndex source tree. Where a fact was not present in the source, it was omitted.

The README's flowchart differs from the executed control flow in the four places listed above; the source tree is authoritative.
