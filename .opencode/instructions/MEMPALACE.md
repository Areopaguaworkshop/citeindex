## Auto-Save Checkpoints

- **After key decisions** → `mempalace_diary_write(wing="wing_citeindex")`: what decided, why, alternatives
- **After bug fixes** → `mempalace_add_drawer(wing="wing_citeindex", room="bugs")`: problem, root cause, solution
- **Before compaction** → emergency diary save with full session context
- **Session end** → diary: accomplishments, open items, next steps

## Search Before Claiming

- `mempalace_search(query="...", wing="wing_citeindex")` before claiming past context
- Present verbatim results, not summaries
- No results? Say so — never fabricate

## Knowledge Graph

- `mempalace_kg_invalidate` — changed facts
- `mempalace_kg_query` — look up relationships
