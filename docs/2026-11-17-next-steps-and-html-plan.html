CiteIndex — HTML Pipeline Hardening & Plan

Evidence-backed web article extraction, deterministic Highwire/JSON-LD parsing, and cryptographic provenance
Scope & Safety Boundary: As instructed, PDF and media pipelines are left untouched. Improvements are strictly targeted to the HTML / URL article pipeline (citeindex/ingestion/pipelines/url_article.py) to deliver evidence-backed metadata parity, zero-dependency academic scraping, and cryptographic snapshot binding.

B

Web Evidence Verification Contract

In accordance with AGENTS.md and citation_verification.py:

  • Metadata Locator Structure: Every HTML metadata block carries: 
    {
  "metadata_key": "citation_doi",
  "snapshot_artifact": "source.html",
  "source_digest": "<sha256>"
}
  • Deterministic Validation: validate_block_evidence validates the quote against the source block text without external calls.
  • Citation Status: When both title and authors are source-supported, _citation_status evaluates to "source-supported".

D

Verification & Remaining Tasks

  1. 1. CJK Citation-Guidance Coverage — Done.
    _find_citation_guidance now recognises the 版权声明 / 版权申明 preambles used by gcdfl.org and ctcfol.org, bare 引用本文 / 引用此文 labels, and _parse_gbt_citation parses GB/T 7714 [J]/[D]/[M]/[C]/[R]/[EB/OL] strings (CNKI, Wanfang, VIP exporters) into CSL fields; run() binds volume / issue / page / type from the guidance block. Policy headings such as "若要引用本文，请参考版权申明" are ignored instead of being returned as the citation. Unlabeled GB/T reference-list lines are accepted only when the parsed title matches the page title, so a bibliography of other works is never adopted as the page's own citation.
  2. 2. Headless Fallback — Implemented.
    _extract_markdown degrades trafilatura markdown → trafilatura plain text → readability-lxml summary text → raw HTML, so a disabled Playwright/headless sandbox still yields body text.
  3. 3. URL Article Benchmark — Done (2026-11-17).
    Reproducible harness: benchmarks/html/run.py with a 20-URL manifest (12 scholarly + 8 reference/blog/news) and no LLM/Zotero calls. Result: 17/20 URLs extractable (1 HTTP 403, 2 bot interstitials); among extractable URLs title, DOI, author, date, and container-title all scored 100%. Raw run: benchmarks/html/results/2026-11-17.json.
  4. 4. Page & Type Field Status — Done.
    citation_firstpage + citation_lastpage (or Prism equivalents) are bound as a joined metadata span, and page ranges validate against both endpoints. type is anchored to citation_journal_title (article-journal), citation_conference_title (paper-conference), or the JSON-LD @type block. Derived pages without an endpoint, and default webpage types, remain unverified rather than claiming false support.
